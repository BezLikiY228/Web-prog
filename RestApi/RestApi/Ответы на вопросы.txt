Контрольные вопросы
1. Что такое Web API?

Web API — это программный интерфейс, который позволяет различным приложениям обмениваться данными через HTTP-запросы.

В ASP.NET Core Web API можно создавать HTTP-методы, которые принимают запросы от клиента и возвращают данные, например в формате JSON.

2. Для чего используется атрибут [ApiController]?

Атрибут [ApiController] используется для обозначения класса как API-контроллера.

Он предоставляет дополнительные возможности для обработки HTTP-запросов, автоматической проверки данных модели и формирования ответов API.

3. Для чего используется [Route]?

Атрибут [Route] определяет маршрут, по которому клиент может обратиться к контроллеру или его методам.

В данной работе используется:

[Route("api/tasks")]

Поэтому основным адресом API является:

/api/tasks
4. Чем отличаются методы GET и POST?

GET используется для получения данных с сервера. Например, с помощью GET можно получить список всех задач или одну задачу по ID.

POST используется для создания нового объекта. В данной работе POST применяется для добавления новой задачи в список.

5. Чем отличаются PUT и DELETE?

PUT используется для изменения существующего объекта.

В данной работе PUT позволяет изменить название, описание и статус задачи.

DELETE используется для удаления существующего объекта из списка.

6. Что означают HTTP-коды 200, 201, 400 и 404?

200 OK означает, что запрос успешно выполнен.

201 Created означает, что новый объект был успешно создан.

400 Bad Request означает, что сервер получил некорректные данные в запросе.

404 Not Found означает, что запрашиваемый объект не найден.
