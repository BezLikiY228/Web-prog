Что такое Web API?

Web API — это программный интерфейс, который позволяет различным приложениям обмениваться данными через интернет или локальную сеть с помощью HTTP-запросов. В ASP.NET Core Web API клиент отправляет запрос серверу и получает ответ, например в формате JSON.

Для чего нужен ControllerBase?

ControllerBase — это базовый класс для API-контроллеров в ASP.NET Core. Он предоставляет готовые методы для формирования HTTP-ответов, например Ok(), NotFound() и BadRequest().

Что делает атрибут [ApiController]?

Атрибут [ApiController] указывает, что класс является API-контроллером. Он упрощает обработку HTTP-запросов, параметров и данных, а также выполняет автоматическую проверку модели.

Для чего используется [Route]?

Атрибут [Route] используется для указания адреса, по которому можно обратиться к контроллеру или его методу. В нашей работе используется маршрут api/[controller]. Так как контроллер называется StudentsController, адрес становится api/Students.

В чем разница между GET и POST?

GET используется для получения данных с сервера. POST используется для отправки данных на сервер, например для добавления нового студента. В нашей работе GET получает список студентов, а POST добавляет нового студента.

Что означает HTTP-код 404 Not Found?

Код 404 Not Found означает, что запрашиваемый ресурс не найден на сервере. В нашей работе этот код возвращается, если студент с указанным Id отсутствует в списке.
