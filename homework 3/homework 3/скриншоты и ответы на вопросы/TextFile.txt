1. Что такое Dependency Injection?

Dependency Injection (DI) — это механизм, который позволяет передавать объекту необходимые зависимости извне, вместо того чтобы создавать их внутри класса с помощью new. В ASP.NET Core зависимости регистрируются в контейнере DI, после чего фреймворк автоматически передаёт их в нужные классы.

2. Зачем использовать интерфейс вместо прямого создания объекта через new?

Интерфейс позволяет отделить класс, который использует сервис, от конкретной реализации этого сервиса. Контроллер работает с IStudentService, а не напрямую с StudentService. Это делает программу более гибкой, облегчает замену реализации и упрощает тестирование.

3. Что такое Constructor Injection?

Constructor Injection — это способ внедрения зависимости через конструктор класса. В нашем проекте IStudentService и ILogger<StudentsController> передаются в конструктор StudentsController. ASP.NET Core автоматически предоставляет необходимые объекты через систему Dependency Injection.

4. Для чего сервис регистрируется в Program.cs?

Сервис регистрируется в Program.cs, чтобы контейнер Dependency Injection знал, какую реализацию необходимо создать при запросе определённого интерфейса. Например, при регистрации:

builder.Services.AddTransient<IStudentService, StudentService>();

ASP.NET Core знает, что при необходимости IStudentService нужно предоставить объект StudentService.

5. Для чего используется ILogger<T>?

ILogger<T> используется для ведения журналов работы приложения. С его помощью можно записывать информацию о выполнении операций, предупреждения и ошибки. В нашем проекте ILogger<StudentsController> используется для отслеживания запросов к API и ситуаций, когда студент не найден или возникает ошибка.

6. Чем отличаются LogInformation, LogWarning и LogError?

LogInformation используется для обычных информационных сообщений о работе приложения, например о получении списка студентов.

LogWarning используется для предупреждений о ситуациях, требующих внимания, например когда студент с указанным идентификатором не найден.

LogError используется для записи ошибок и исключений, которые произошли во время выполнения операции.




Transient создаёт новый экземпляр сервиса каждый раз, когда зависимость запрашивается из контейнера Dependency Injection.

Singleton создаёт один экземпляр сервиса, который используется в течение всего времени работы приложения.
